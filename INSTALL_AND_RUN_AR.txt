                         دليل تثبيت وتشغيل الوهيب ERP
                           AL-WAHIB ERP • 2026-10-26
===========================================================================

تنبيه مهم: المرفق مشروع مصدر برمجي أولي. لم يجتز build أو التشغيل الفعلي في
بيئة إنشاء الملفات لعدم توفر Windows/.NET 10 هنا. لا تستعمله ببيانات مالية
حقيقية قبل أن ينجح الاختبار المحلي ويعتمده محاسب. تفاصيل النقص في:
    docs\ENGINEERING_NOTES.md
    docs\FEATURE_COVERAGE.csv
    docs\TEST_EVIDENCE.md

[1] النظام والبرامج المطلوبة
----------------------------
- نظام تشغيل: Windows 10/11 بنواة x64 (نسخة 64 بت موصى بها).
- .NET 10 SDK للـ Windows x64 (وليس Runtime فقط)، على سبيل المثال 10.0.402:
  https://dotnet.microsoft.com/en-us/download/dotnet/10.0
- VS Code (اختياري لفتح/تعديل الكود، وليس شرطًا لتشغيل سكربتات CMD):
  https://code.visualstudio.com/
- إضافات VS Code: C# (ms-dotnettools.csharp)، C# Dev Kit اختياري.
- إنترنت في المرة الأولى لتحميل حزمة NuGet Microsoft.Data.Sqlite 10.0.13.
- لا حاجة إلى MySQL أو XAMPP أو Flutter أو Android Studio أو Python.

[2] فك الضغط
-------------
1. فك ملف AL_WAHIB_ERP_SOURCE.zip في مجلد بلا تعقيد في الاسم، مثل:
   C:\Projects\AlWahibERP
2. ادخل المجلد بحيث ترى AlWahibERP.slnx و01-FIRST-RUN.cmd.
3. في VS Code: File > Open Folder > اختر هذا المجلد الجذر.
4. لا تنقل ملفات .cs منفردة؛ احتفظ بكل المجلدات والمشاريع.

[3] التثبيت والتحقق
---------------------
افتح Terminal في VS Code (Ctrl+`) أو PowerShell داخل مجلد المشروع ثم اكتب:

    dotnet --info
    dotnet --version

يجب أن ترى SDK يحمل الرقم 10.x. في حال ظهور 'dotnet is not recognized':
أعد تثبيت SDK 10، أغلق VS Code وافتحه مجددًا، وتحقق من PATH.

[4] التشغيل التلقائي (الأبسط)
-----------------------------
انقر مرتين:

    01-FIRST-RUN.cmd

الأوامر التي ينفذها بنفسه:
  1. dotnet restore AlWahibERP.slnx
  2. dotnet build AlWahibERP.slnx -c Debug --no-restore
  3. dotnet run --project tests\Wahib.Tests\Wahib.Tests.csproj -c Debug --no-restore
  4. dotnet run --project src\Wahib.Desktop\Wahib.Desktop.csproj -c Debug --no-restore

**مهم:** إذا فشل البناء أو أي اختبار سيتوقف السكربت ولن يعلن نجاحًا وهميًا.
الرجاء الاحتفاظ بنص الخطأ إذا احتجت إصلاحًا.

[5] التشغيل من Terminal يدويًا
------------------------------
    dotnet restore .\AlWahibERP.slnx
    dotnet build .\AlWahibERP.slnx -c Debug --no-restore
    dotnet run --project .\tests\Wahib.Tests\Wahib.Tests.csproj
    dotnet run --project .\src\Wahib.Desktop\Wahib.Desktop.csproj

في المرات التالية شغّل 02-RUN-APP.cmd مباشرة بعد نجاح البناء الأول.
لإعادة الاختبارات: 03-RUN-TESTS.cmd.

[6] الإعداد عند أول فتح
------------------------
- اختر اسم شركتك أو المحل.
- اختر عملة الأساس: YER أو SAR أو USD. النظام يعمل بعملة أساس واحدة للشركة.
- أنشئ كلمة مرور قوية لا تقل عن 10 أحرف.
- اسم دخول مالك الشركة الأول هو: owner
- سجّل الدخول بهذه البيانات؛ لا توجد كلمة مرور افتراضية جاهزة.
- قاعدة كل شركة تُحفظ في:
  %LOCALAPPDATA%\AlWahibERP\companies\<company-id>.db
- سجل الشركات في:
  %LOCALAPPDATA%\AlWahibERP\companies.json
لا تحفظ ملفات العمل داخل مجلد كود المشروع.

[7] مثال تشغيل محاسبي آمن باستخدام بيانات اختبارية
---------------------------------------------------
1. من 'العملاء والموردون': أنشئ موردًا وعميلًا.
2. من 'الأصناف والمخزون': أضف صنفًا، مثل TEST-01، وسعر بيع 150.
3. من 'الأستاذ والقيود': افتح '+ قيد يومية من حسابين'؛
   مدين: الصندوق 1010 | دائن: رأس المال 3100 | المبلغ: 100000.
4. من 'الفواتير': '+ شراء'، اختر المورد، الكمية 50، تكلفة الوحدة 100،
   طريقة الدفع آجل ثم حفظ مسودة.
5. اختر مسودة الشراء واضغط 'ترحيل المسودة'. الآن في المخزون 50.
6. أنشئ فاتورة بيع آجل: 20 قطعة بسعر 150، ثم ترحيلها.
7. من 'الصندوق والسداد': اختر فاتورة البيع، أنشئ سند قبض 1000.
8. من شاشة الفواتير اختر فاتورة البيع المرحلة، اضغط 'مرتجع بيع'،
   ثم أرجع قطعتين، ومرحّل المستند.
9. من 'التقارير': ميزان المراجعة، قائمة الدخل، المركز المالي.
10. من 'الإدارة والصيانة': فحص سلامة، ثم إنشاء نسخة احتياطية.

ملاحظة: الصنف لا يبدأ برصيد موجب بدون حركة شراء معتمدة؛ إدخال رصيد افتتاحي
بكلفة محددة يحتاج مسار ترحيل افتتاحي إضافي قبل التشغيل التجاري.

[8] الطباعة إلى PDF
-------------------
اختر فاتورة، ثم 'طباعة A4 / PDF'، ومن قائمة طابعات Windows اختر:
    Microsoft Print to PDF
ثم احفظ الملف من نافذة النظام. إن كانت الطابعة غير موجودة فعّلها من
Windows Optional Features. دعم الطابعة الحرارية 80mm غير منفذ في هذه النسخة.

[9] النسخ الاحتياطي والاستعادة
--------------------------------
- افتح 'المستخدمون والنسخ' بدور المالك.
- اختر 'نسخة احتياطية آمنة' وحدد مجلدًا خارج بيانات البرنامج.
- سيُنشأ ملفان متلازمان:
    backup.db
    backup.db.manifest.json
- احتفظ بالملفين معًا؛ تحتاجهما الاستعادة.
- الاستعادة تتأكد من SHA256 والشركة والإصدار، ثم تغلق التطبيق بعد الاستعادة.
- احتفظ بنسخة أخرى على قرص خارجي مُؤمّن ولا تعتمد على نفس القرص.

[10] نشر نسخة تشغيلية Windows x64
----------------------------------
بعد أن ينجح البناء والاختبار، انقر:
    04-PUBLISH-WINDOWS-X64.cmd
أو نفّذ:
    dotnet publish .\src\Wahib.Desktop\Wahib.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\published\win-x64
الملفات الناتجة في published\win-x64؛ لم يجر التحقق من تشغيل حزمة Publish
فعليًا على Windows نظيف هنا. قبل التوزيع تحتاج توقيع تطبيق، Installer، اختبارات
ترقية وقواعد تراخيص قانونية.

[11] حلول الأخطاء المشهورة
----------------------------
* 'dotnet' غير معروف:
  ثبّت .NET SDK وليس Runtime فقط وأعد فتح VS Code.
* NETSDK1045 أو نسخة SDK لا تدعم net10.0:
  استخدم SDK 10.x وتحقق من dotnet --list-sdks.
* NU1301 / Unable to load service index:
  تحتاج إنترنت عند أول restore. تحقق من الوصول إلى api.nuget.org.
* Package restore failed:
  افتح Terminal واضغط 'dotnet restore AlWahibERP.slnx' لقراءة الخطأ.
* خطأ WindowsDesktop WPF على Linux/macOS:
  الواجهة تعمل على Windows فقط؛ الاختبارات غير الرسومية قد تعمل على منصة أخرى.
* لا يظهر الحساب أو الفاتورة في التقرير:
  تأكد من حالة Posted وأن التاريخ ضمن الفلتر والفترة غير مغلقة.
* ترحيل فاتورة يرفض نقص الكمية:
  أنشئ فاتورة شراء صحيحة ومرحلة أولًا؛ لا تدخل مخزونًا سالبًا.
* اكتشاف قاعدة قديمة:
  لا تغيّر schema_version يدويًا؛ استخدم النسخة المتوافقة أو خطة هجرة.
* تشغيل بعد استعادة:
  أغلق البرنامج تمامًا وافتحه مجددًا وسجل دخولك ببيانات النسخة المستعادة.

التقارير والتكاليف واختبارات Windows المؤكدة. لا تستخدمه لإثبات امتثال ضريبي.
