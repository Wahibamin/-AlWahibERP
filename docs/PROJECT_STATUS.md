- لا يوجد ضمن حزمة GitHub قاعدة بيانات شركة تشغيلية، ملف EXE جاهز، حزمة Installer، أو ملف ترخيص.

## نقاط هندسية ملحوظة

- الأموال والكميات تستخدم أسلوب fixed-point في C# وقيم INTEGER في SQLite، وفقًا للكود.
- ترحيل المستندات يعتمد معاملات SQLite، وتوجد قواعد برمجية لمنع المخزون السالب والقيود غير المتوازنة.
- توجد آليات أساسية لتسجيل المستخدمين وحظر الصلاحيات بحسب الدور؛ لا توصف كحل أمني مكتمل.
- الواجهة عربية WPF RTL؛ بعض عناوين DataGrid الافتراضية ما تزال بالإنجليزية كما يظهر في لقطة لوحة التحكم.
- `.NET 10` و`Microsoft.Data.Sqlite 10.0.13` منصوص عليهما في ملفات المشاريع.
- مرجع المشروع أكبر من التنفيذ الحالي. الملف `FEATURE_COVERAGE.csv` يوثق **106 متطلبات وظيفية و37 غير وظيفية** وحالات تشمل نواة منفذة، جزئي، أو غير منفذ/غير مثبت.

## حدود التحقق

- لم يكن بالإمكان هنا تشغيل واجهة WPF (تستلزم Windows)، ولم يُجرَ `dotnet build` أو `dotnet run` جديد في إعداد هذه الحزمة.
- وجود كود أو اختبار لا يساوي اجتيازه؛ وأي تقرير محاسبي يحتاج تحققًا فعليًا قبل استخدامه.
- هذه نسخة **للعرض البرمجي والتوثيق والملف الشخصي على GitHub** وليست نسخة إنتاج جاهزة.

## ما استُبعد من حزمة GitHub النظيفة

- ملفات `bin/`, `obj/`, `.vs/`, `.git/`, قواعد البيانات الحقيقية والنسخ التشغيلية إن وجدت.
- ملفات إصلاح مرحلية `WAHIB_HOTFIX_01/`, `WAHIB_HOTFIX_02/`, `WAHIB_DRAFT_DIAGNOSTIC_03/` الموجودة في أرشيف الاستلام؛ جرى الاحتفاظ بها في الأصل فقط ولا يعتمد تشغيل المصدر عليها ضمن الحل.
- ملفات نسخ C# المؤقتة ذات الامتداد `.period-backup` وملف `CHECKSUMS.sha256` القديم الذي لم يعد يطابق الحزمة المنظّمة. استُبدل بقائمة تحقق جديدة للمصدر الأساسي.
