# أدلة التحقق

- مكتوب: `tests/Wahib.Tests/Program.cs` يحتوي اختبارات وحدات لنظام Fixed-point وMovingAverage، واختبارات تكامل SQLite لسلسلة المثال الوارد في مخطط v1.1 القسم 15.4.
- الفحوص المستهدفة: 50 مشتريات + 20 مبيعات + 1000 قبض + 2 مرتجع + 8 شراء + 5 مبيعات + عجز 1؛ المتوقع مخزون 34 وقيمة 3570، نقد 101000، ذمم 2550، موردون 6000، صافي ربح 1120، أصول 107120.
- قواعد سلبية: رفض قيد غير متوازن، عدم مضاعفة ترحيل فاتورة، منع مخزون سالب، رفض قيد يدوي لحساب المخزون الضابط، قفل الفترة، فحص تتابع الـAudit، وإنشاء نسخة مع Manifest.
- **حالة التنفيذ في بيئة إعداد الملفات:** تعذر تنفيذ dotnet build وdotnet run لأن .NET SDK وWindows/WPF غير متوفرين على الخادم. لا تدّعي هذه الوثيقة نجاح تشغيل الاختبارات البرمجية. يجب تشغيل `03-RUN-TESTS.cmd` فعليًا على Windows مع .NET 10 SDK وحفظ الـconsole log قبل أي استخدام تجاري.
- **فحص تم بالفعل:** اختبار تحليل وإنشاء SQL DDL باستخدام Python sqlite3؛ إنشاء 17 جدولًا نجح وPRAGMA foreign_key_check فارغ.
- لا توجد نتائج اختبارات Windows UI/RTL أو Windows printing/BackupDatabase أو أداء أو أمان أو فحص ضريبي من جهة مختصة.
