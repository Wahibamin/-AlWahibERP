# قائمة قبول إلزامية على Windows قبل التعامل بأموال فعلية

هذه قائمة اختبارات **لم تُنفذ** في بيئة إنشاء الملفات. سجّل لكل بند PASS/FAIL وصورة ووقت التطبيق. لا يجوز الاستدلال على النجاح من مجرد وجود الكود.

## G0: Build and Package
- [ ] تثبيت Windows 10/11 x64 نظيف مع .NET 10 SDK 10.0.402 أو أحدث.
- [ ] `dotnet --info` يطبع SDK 10.
- [ ] `dotnet restore AlWahibERP.slnx` ناجح.
- [ ] `dotnet build AlWahibERP.slnx -c Release` ناجح **0 أخطاء**.
- [ ] `03-RUN-TESTS.cmd` ينتهي برسالة `ALL ... CHECKS PASSED` وexit code 0.
- [ ] `04-PUBLISH-WINDOWS-X64.cmd` ينشئ ملف EXE قابلًا للفتح على Windows x64 جديد.
- [ ] لا توجد أعطال UI أو أخطاء Runtime لأول تشغيل دون إنترنت بعد Restore.

## G1: مالية ومخزون
- [ ] لا يستطيع المستخدم حفظ قيد غير متوازن؛ لا أثر جزئي.
- [ ] نفس فاتورة البيع لا ترحّل مرتين بعد نقر F9 مرتين.
- [ ] فشل فاتورة بلا كمية مخزون يترك الرصيد السابق كما هو.
- [ ] مثال 15.4 ينتج 34 حبة/3,570 قيمة و2,550 عميل و6,000 مورد و1,120 ربح.
- [ ] مجموع الميزان مدين = دائن.
- [ ] قيمة دفتر المخزون = رصيد حساب الأصل 1200.
- [ ] مردود البيع يستخدم التكلفة التاريخية حتى إن تغير المتوسط لاحقًا.
- [ ] مردود الشراء يسجل فرق سعر الشراء دون اختفاء قيمة مخزون.
- [ ] لا يمكن إرجاع أكثر من الكمية الأصلية.
- [ ] الفاتورة النقدية لا تبقي ذمة مفتوحة.
- [ ] سند القبض الجزئي لا يتجاوز المتبقي ويغيّر ذمة العميل.
- [ ] مغلق الفترة يرفض كافة مسارات الترحيل.
- [ ] تأريخ مخزني أقدم من آخر حركة للصنف يرفض.
- [ ] إدخال مبالغ قصوى أو كسور دقيقة يرفض overflow ولا يغير الأرصدة.
- [ ] قطع الكهرباء أو قتل التطبيق أثناء COMMIT لا يخلف قيدًا دون حركة مخزون.

## G2: المستخدمون والتشغيل
- [ ] كلمة مرور التأسيس ليست ثابتة ولا تعرض في الواجهة.
- [ ] تجربة 5 تسجيلات خاطئة تُفعّل الحد المؤقت.
- [ ] مستخدم Cashier لا يستطيع ترحيل قيد يومية.
- [ ] مستخدم Viewer لا يستطيع إنشاء مستند مرحّل أو الاطلاع على حساب تكلفة عبر أي مسار (يتطلب إصلاح RBAC قبل الاعتماد التجاري).
- [ ] فحص EventHash يكشف تعديل سجل داخل قاعدة اختبارية.
- [ ] نسخ SQLite أثناء عمليات كتابة نشطة ثم فحص النسخة المستعادة على جهاز مستقل.
- [ ] تجربة نسخة ملف تالف لا تستبدل قاعدة الأصل.
- [ ] استعادة نسخة سليمة تحفظ الملف السابق للرجوع.
- [ ] نسخ الشركة A لا يُقبل لشركة B.
- [ ] حذف/تحديث ملفات البرنامج لا يمحو `%LOCALAPPDATA%/AlWahibERP`.

## G3: تجربة المستخدم
- [ ] كل عناصر الواجهة العربية RTL سليمة عند مقياس DPI 100/125/150%.
- [ ] يمكن فتح وقراءة CSV العربية في Excel بدون فقد الحروف.
- [ ] تدفق الفاتورة متعدد البنود مع كرّر الاختصار F9.
- [ ] طباعة A4 PDF تطابق مجموع الأستاذ، بدون قص عناوين عربية.
- [ ] المستخدم لا يرى رسالة خطأ تقنية حساسة أو كلمة مرور في السجلات.
- [ ] اختبار كامل بدون إنترنت بعد restore الحزم لأول مرة.

- [ ] تحويلات الكرتون/الحبة وأجهزة باركود وطابعة 80mm.
